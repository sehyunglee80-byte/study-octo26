# 비트코인 120일·200일선 2% 여유 폭 매일 신호 (반자동 매매)

매일 아침 업비트 일봉 마감 직후, 비트코인을 들고 있어야 하는지 현금으로 있어야 하는지 텔레그램으로 알려 줍니다.
매매는 알림을 보고 직접 업비트에서 합니다.

## 규칙
- 매일 09:00 KST(업비트 일봉 마감) 직후, 마감된 전날 종가로 판단합니다.
- **현금일 때:** 종가가 120일선과 200일선을 **둘 다 2% 넘게 웃돌면 매수**
- **보유일 때:** 종가가 120일선이나 200일선 중 **하나라도 2% 넘게 밑돌면 매도**
- 그 사이에서는 직전 포지션을 그대로 유지합니다. 이평선 근처에서 사고팔기를 반복하지 않게 하는 장치입니다.
- 포지션은 매번 2022-01-03부터 같은 규칙으로 다시 계산합니다. 상태 파일이 어긋나도 스스로 맞춰집니다.

백테스트 (`btc-upbit-ma/backtest.py`, 2022-01-03 → 2026-10-07, 수수료 0.05% 반영)

| 방식 | 누적 | 최대낙폭 | 매매 |
|---|---|---|---|
| 여유 폭 2% (이 알림) | +351% | -21.0% | 7 |
| 여유 폭 없음 | +308% | -26.5% | 16 |
| 주 1회 200일선 | +273% | -28.4% | 7 |

여유 폭 1.75%부터 3%까지는 최대낙폭이 -20%에서 -21% 사이로 비슷했습니다. 2%는 그 가운데 값입니다.

## 알림 종류
| 알림 | 할 일 |
|---|---|
| 🟢 매수 신호 | 원화로 BTC 매수 |
| 🔴 매도 신호 | BTC 전량 매도 |
| ⚪ 유지 | 아무것도 하지 않음 (매일 오는 정상 작동 확인용) |
| ⚠️ 신호 계산 실패 | Actions 탭에서 수동 실행해 다시 확인 |

알림마다 다음 매수·매도 기준 가격(높은 쪽 이평선 ±2%)이 함께 옵니다. 이평선은 매일 조금씩 바뀌므로 그날 기준입니다.

## 실행 방식
- `.github/workflows/btc-ma-band-daily.yml`이 매일 09:05, 09:35, 10:05 KST에 실행됩니다. 하루에 알림은 한 번만 갑니다.
- 처리한 날과 현재 포지션은 `state.json`에 저장되고 자동 커밋됩니다. 매일 커밋이 생기므로 예약 실행이 멈추지 않습니다.
- 텔레그램 Secret `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`는 기존 알림과 같은 값을 씁니다.

연결 확인: Actions 탭 → `BTC MA 2% band daily signal` → Run workflow (manual 체크) → 현재 상태가 텔레그램으로 옵니다.

## 로컬 실행
```bash
MANUAL=1 python btc-ma-band-daily/signal.py                                       # 현재 상태 확인
NOW=2025-02-25T09:05 STATE_FILE=/tmp/s.json python btc-ma-band-daily/signal.py    # 과거 날짜 재현
```
