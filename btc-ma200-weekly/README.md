# 비트코인 200일선 주간 신호 알림 (반자동 매매)

> 예약 실행은 꺼져 있습니다. 현재 쓰는 알림은 [`btc-ma-band-daily`](../btc-ma-band-daily/README.md)(120·200일선 2% 여유 폭 매일 신호)입니다. 수동 실행은 그대로 됩니다.

매주 월요일 아침, 이번 주에 비트코인을 들고 있어야 하는지 현금으로 있어야 하는지 텔레그램으로 알려 줍니다.
매매는 알림을 보고 직접 업비트에서 합니다.

## 규칙
- 매주 월요일 09:00 KST(업비트 일봉 마감) 직후 판단합니다.
- 마감된 일요일 종가가 최근 200개 마감 종가 평균(200일 이동평균)보다 높으면 **보유**, 아니면 **현금**입니다.
- 진행 중인 오늘 봉은 쓰지 않습니다. `backtest_momentum.py` 데이터로 검증한 백테스트와 같은 기준입니다.
  2022-01-03부터 2026-10-07까지 매매 13번, 누적 +271%, MDD -28.7% (`charts/btc_ma200_weekly.html`).

## 알림 종류
| 알림 | 할 일 |
|---|---|
| 🟢 매수 신호 | 원화로 BTC 매수 |
| 🔴 매도 신호 | BTC 전량 매도 |
| ⚪ 유지 | 아무것도 하지 않음 (매주 오는 정상 작동 확인용) |
| ⚠️ 신호 계산 실패 | Actions 탭에서 수동 실행해 다시 확인 |

## 실행 방식
- `.github/workflows/btc-ma200-weekly.yml`이 월요일 09:05, 09:35, 10:05 KST에 실행됩니다.
  예약 실행이 늦거나 빠질 때를 대비한 것이고, 한 주에 알림은 한 번만 갑니다.
- 처리한 주와 현재 포지션은 `state.json`에 저장되고 자동 커밋됩니다. 매주 커밋이 생기므로 예약 실행이 멈추지 않습니다.
- 워크플로는 저장소 기본 브랜치에 있어야 예약 실행됩니다.

## 설정
텔레그램 Secret `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`를 씁니다. 기존 120일선 알림에 등록한 값을 그대로 씁니다.
등록 방법은 `btc-ma120/README.md`를 참고하세요.

연결 확인: Actions 탭 → `BTC MA200 weekly signal` → Run workflow (manual 체크) → 현재 상태가 텔레그램으로 옵니다.

## 직접 매매했을 때 상태가 어긋나면
`state.json`의 `position`은 "알림 기준 포지션"입니다. 실제 보유와 상관없이 신호가 바뀔 때만 매수/매도 알림을 보냅니다.
상태를 바로잡아야 하면 `position`을 `hold` 또는 `cash`로 고쳐 커밋하세요.

## 로컬 실행
```bash
MANUAL=1 python btc-ma200-weekly/signal.py                 # 현재 상태 확인
NOW=2026-08-24T09:05 STATE_FILE=/tmp/s.json python btc-ma200-weekly/signal.py   # 과거 월요일 재현
```
