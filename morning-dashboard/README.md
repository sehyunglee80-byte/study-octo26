# 아침 지표 대시보드 데이터

`fetch.py` 가 야후 파이낸스에서 지표를 받아 `data.json` 에 저장한다. GitHub Actions(`morning-dashboard.yml`)가 실행하고,
Claude 예약 작업이 매일 07:40 KST 에 워크플로를 실행한 뒤 `data.json` 으로 대시보드를 갱신한다.

- S&P 500, 나스닥 100, SOXL, 코스피, 미국 10년물 금리, VIX, 금, WTI 유가, 비트코인: 최근 종가, 전일 대비, 종가 기준 전고점과 전고점 대비 %
- 원달러: 직전 15:30 KST 환율, 최근 3년 롤링 평균
- 차트용 history.csv 에 50일·200일 이동평균 포함
- 대시보드용 CSV는 가격을 정수(SOXL은 소수점 첫째 자리), 증감률을 소수점 첫째 자리로 반올림

지표 추가: `fetch.py` 의 `INDEXES` 에 (키, 야후 티커, 이름)을 넣는다.
